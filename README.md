# CelebrAI — AI-Powered Event Planning Platform

CelebrAI is a full-featured, AI-powered event planning web application built with React 19, TypeScript, Vite, Firebase Authentication, Cloud Firestore, and Groq GPT-OSS 120B.

## Brand Identity & Design System
- **Soft Satin (`#F7F1E8`)**: Application canvas background
- **Bridal White (`#FFFFFF`)**: Card surfaces, modals and inputs
- **Morning Fog (`#ECE6DE`)**: Subtle borders and dividers
- **Violet (`#D8CBF1`)**: Brand accents, selected states, and AI highlights
- **Tuxedo Black (`#171F20`)**: Primary buttons and titles
- **Typography**: Playfair Display (editorial serif) & DM Sans (clean interface sans-serif)
